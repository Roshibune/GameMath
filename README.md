# GameMath

GameMath é um jogo web educativo para apoiar alunos do 4º ano do Ensino Fundamental na aprendizagem de multiplicação e divisão.

O MVP terá uma área do aluno para jogar e uma área do professor para acompanhar o desempenho dos alunos vinculados por código. As perguntas e explicações serão fornecidas pelo grupo de Pedagogia parceiro do projeto.

## Tecnologias

- Astro
- JavaScript
- Supabase — autenticação e banco de dados
